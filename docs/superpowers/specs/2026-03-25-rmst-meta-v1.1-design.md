## Background

RMST Meta v1.0 is a working browser tool for meta-analysis of Restricted Mean Survival Time differences. It supports DerSimonian-Laird random-effects pooling, HKSJ-adjusted CIs, prediction intervals, leave-one-out sensitivity, tau-horizon sensitivity, forest plots, funnel plots, and R code export.

Three gaps were identified for Stat Med publication standard:

1. **REML estimator** — DL underestimates tau-squared; REML is the modern default
2. **Egger's test** — funnel plot without formal asymmetry testing is incomplete
3. **Plot exports** — no way to download figures for journal submission

## 1. REML Estimator

### Algorithm (Viechtbauer 2005, JRSS-B)

Fisher scoring iterative algorithm to maximize the restricted log-likelihood.

**Definitions:**
- `vi = si^2` (within-study variance)
- `wi* = 1/(vi + tau2)` (random-effects weight at current tau2)
- `mu* = sum(wi* * yi) / sum(wi*)` (weighted mean at current tau2)
- `P = sum(wi*^2 * (yi - mu*)^2)` (weighted residual sum of squares)

**Restricted log-likelihood** (up to constants):
```
l_R(tau2) = -0.5 * [sum(log(vi + tau2)) + log(sum(wi*)) + sum(wi* * (yi - mu*)^2)]
```

**Fisher scoring update** (Viechtbauer 2005, eq. 3-4):
```
Score:    dl/dtau2 = -0.5 * [sum(wi*) - sum(wi*^2)/sum(wi*) - P]
                   = -0.5 * [(k-1)/k_eff_approx - P]   (informally)

Fisher information:  I(tau2) = 0.5 * [sum(wi*^2) - 2*sum(wi*^3)/sum(wi*) + (sum(wi*^2)/sum(wi*))^2]

Update:   tau2_new = max(0, tau2 + score / information)
                   = max(0, tau2 + [P - sum(wi*) + sum(wi*^2)/sum(wi*)]
                                  / [sum(wi*^2) - 2*sum(wi*^3)/sum(wi*) + (sum(wi*^2)/sum(wi*))^2])
```

**Note on the numerator sign:** `score = -0.5 * [A - P]` where `A = sum(wi*) - sum(wi*^2)/sum(wi*)`. The update adds `score / information`, so numerator = `(-A + P) / (-2 * 0.5) * 1/(0.5*I_raw)` simplifies to `(P - A) / I_raw`. This is equivalent to `[P - (sum(wi*) - sum(wi*^2)/sum(wi*))] / [sum(wi*^2) - 2*sum(wi*^3)/sum(wi*) + (sum(wi*^2)/sum(wi*))^2]`.

**Parameters:**
- Convergence tolerance: `|tau2_new - tau2_old| < 1e-8`
- Max iterations: 100
- Warm start from DL tau-squared estimate
- Floor at tau2 = 0 (non-negative constraint, applied each iteration)

**Self-check after convergence:** Compute `Q_RE = sum(wi* * (yi - mu*)^2)` with final REML weights. At convergence, the score should be ~0, meaning `Q_RE ≈ sum(wi*) - sum(wi*^2)/sum(wi*)`. Log a warning (internal) if residual score > 1e-4.

### Non-convergence fallback

If REML does not converge within 100 iterations:
- Set `converged = false` in the result
- **Still display REML results** (last iteration values) with a visible warning: "REML did not converge; results approximate"
- The comparison card shows both DL and REML with the warning badge
- Forest plot shows the REML diamond but with a dashed outline instead of solid
- Report text includes: "Note: REML did not converge within 100 iterations; DerSimonian-Laird results may be preferred."

### Q statistic

The Cochran Q statistic and its p-value are **always computed using fixed-effect weights** (as in v1.0), not REML weights. Q is defined as `sum(wi_FE * (yi - mu_FE)^2)` where `wi_FE = 1/vi`. This is invariant to the tau-squared estimator. Both the DL and REML results share the same Q and pQ values.

### k=2 edge case

REML is valid for k >= 2 but with only 2 studies:
- REML frequently converges to tau2 = 0 (flat likelihood), making it equivalent to fixed-effect
- DL may give tau2 > 0 in the same scenario
- The comparison card suppresses difference highlighting for k=2 and shows a note: "With only 2 studies, tau-squared estimates are unreliable"

### Function signature

```javascript
function remlMeta(diffs, ses) -> {
  k, est, se, ci, tau2, I2, Q, pQ, pi, hksj, weights, diffs, ses,
  converged, iterations
}
```

Returns the same structure as `dlMeta()` plus convergence info. All downstream code (forest plot, analysis, report) works with either result object.

## 2. Egger's Test for Funnel Plot Asymmetry

### Algorithm (Egger et al. 1997 — unweighted OLS)

This implements the original Egger's test as **ordinary least squares** (not WLS), matching `metafor::regtest(model="lm")`:

```
zi = yi / sei       (standardized effect)
pi = 1 / sei        (precision)

Model: zi = beta0 + beta1 * pi + epsilon
```

**Closed-form OLS formulas** (k studies, vectors z and p):

```
p_bar = mean(pi)
z_bar = mean(zi)

Spp = sum((pi - p_bar)^2)
Spz = sum((pi - p_bar) * (zi - z_bar))

beta1 = Spz / Spp                          (slope)
beta0 = z_bar - beta1 * p_bar              (intercept)

residuals: ei = zi - beta0 - beta1 * pi
MSE = sum(ei^2) / (k - 2)

SE(beta0) = sqrt(MSE * (1/k + p_bar^2 / Spp))
SE(beta1) = sqrt(MSE / Spp)

t = beta0 / SE(beta0)
df = k - 2
p-value = 2 * (1 - tCDF(|t|, df))
```

Requires k >= 3 (need df >= 1).

**Interpretation thresholds:**
- p < 0.10: "Evidence of funnel plot asymmetry (consider publication bias)"
- p >= 0.10: "No evidence of funnel plot asymmetry"
- Always show: "Egger's test has low power with fewer than 10 studies"

### tCDF function (new dependency)

Egger's test requires a `tCDF(x, df)` function. Implementation: use the regularized incomplete beta function relationship:

```
tCDF(x, df) = 1 - 0.5 * I_x2(df/2, 0.5)
where x2 = df / (df + x*x)
and I_x2 is the regularized incomplete beta function
```

For simplicity, approximate using the normal CDF for df > 100 and the Hill (1970) algorithm or continued fraction expansion for smaller df. Alternatively, invert the existing `tQuantile()` via bisection search (simpler, ~20 iterations for 1e-8 precision).

### Egger's regression line on funnel plot

The regression `zi = beta0 + beta1 * pi` transforms to funnel-plot coordinates (yi, sei):

```
yi / sei = beta0 + beta1 / sei
=> yi = beta0 * sei + beta1
```

This is a **straight line in (yi, sei) space**: at `sei = 0`, `yi = beta1` (the slope = pooled estimate at infinite precision); at `sei = maxSE`, `yi = beta0 * maxSE + beta1`.

Draw as a dashed line in the funnel plot from `(beta1, 0)` to `(beta0 * maxSE + beta1, maxSE)`, clipped to the plot area.

### Function signature

```javascript

  intercept, interceptSE, slope, slopeSE, t, df, pValue
}
```


## 3. SVG + PNG Export

### Implementation

Two buttons per chart card (forest plot and funnel plot):

**SVG export:**
1. Get `innerHTML` of the chart container (already valid SVG)
2. Wrap in XML declaration + xmlns attribute
3. Create `Blob` with MIME type `image/svg+xml`
4. Create temporary `<a>` element, `appendChild` to body (Firefox compatibility), set `href` to `URL.createObjectURL(blob)`
5. Trigger click, then `URL.revokeObjectURL()` and remove element

**PNG export:**
1. Serialize SVG to data URL via `XMLSerializer`
2. Create `Image`, set `src` to data URL
3. On `Image.onload`, draw to offscreen `<canvas>` at 2x resolution (retina)
4. Call `canvas.toBlob()` for PNG
5. **Error handling:** if `canvas.toBlob()` returns null or errors, show alert "PNG export failed — try SVG instead"
6. Download via same Blob URL pattern, then revoke

**Safety note:** The SVGs are self-generated and never contain `<script>` tags or external references. The export functions construct XML strings but do not embed user-controlled markup that could contain `</script>`. This invariant is asserted by comment in the code.

### Filenames

- `rmst-forest-plot.svg` / `rmst-forest-plot.png`
- `rmst-funnel-plot.svg` / `rmst-funnel-plot.png`

### Display

- Export buttons added to card headers (alongside existing elements):
  - `[SVG]` `[PNG]` small secondary buttons
- Buttons only visible after analysis has been run (hidden when chart is empty)
