## Background

RMST Meta v1.0 is a working browser tool for meta-analysis of Restricted Mean Survival Time differences. It supports DerSimonian-Laird random-effects pooling, HKSJ-adjusted CIs, prediction intervals, leave-one-out sensitivity, tau-horizon sensitivity, forest plots, funnel plots, and R code export.

Three gaps were identified for Stat Med publication standard:

1. **REML estimator** — DL underestimates tau-squared; REML is the modern default
2. **Egger's test** — funnel plot without formal asymmetry testing is incomplete
3. **Plot exports** — no way to download figures for journal submission

## 1. REML Estimator

### Algorithm

Fisher scoring iterative algorithm to maximize the restricted log-likelihood:

```
REML(tau2) = -0.5 * [sum(log(si^2 + tau2)) + log(sum(wi*)) + sum(wi*(yi - mu*)^2)]
```

where `wi* = 1/(si^2 + tau2)` and `mu* = sum(wi* * yi) / sum(wi*)`.

**Update step** (Newton-Raphson on first derivative):

```
tau2_new = tau2 + [sum(wi*^2 * (yi - mu*)^2) - sum(wi*) + sum(wi*^2)/sum(wi*)]
           / [sum(wi*^2) - 2*sum(wi*^3)/sum(wi*) + (sum(wi*^2))^2/(sum(wi*))^2]
```

Simplified: use the iterative REML estimator from Viechtbauer (2005).

**Parameters:**
- Convergence tolerance: `|tau2_new - tau2_old| < 1e-8`
- Max iterations: 100
- Warm start from DL tau-squared estimate
- Floor at tau2 = 0 (non-negative constraint)

### Function signature

```javascript
function remlMeta(diffs, ses) -> {
  k, est, se, ci, tau2, I2, Q, pQ, pi, hksj, weights, diffs, ses,
  converged, iterations
}
```

Returns the same structure as `dlMeta()` plus convergence info. All downstream code (forest plot, analysis, report) works with either result object.

### Display

- **Analysis tab**: New "Estimator Comparison" card showing DL vs REML side-by-side:
  - Pooled estimate, 95% CI, SE, tau-squared, I-squared for each
  - Highlight differences (color-code if > 5% relative difference)
- **Forest plot**: REML diamond as primary; DL shown as a thin outline diamond below for comparison
- **HKSJ and PI**: Recomputed using REML tau-squared (shown alongside DL-based versions in comparison card)
- **Report tab**: Methods text updated to mention both DL and REML; results table uses REML as primary

## 2. Egger's Test for Funnel Plot Asymmetry

### Algorithm

Weighted linear regression (Egger et al., 1997):

```
yi / sei = beta0 + beta1 * (1/sei) + error
```

Equivalently: regress standardized effects `zi = yi/sei` on precision `pi = 1/sei`.

- **Test statistic**: `t = beta0 / SE(beta0)`, df = k - 2
- **p-value**: two-sided t-test
- **Interpretation**: significant intercept (p < 0.10 by convention) suggests asymmetry

### Function signature

```javascript
function eggerTest(diffs, ses) -> {
  intercept, interceptSE, slope, slopeSE, t, df, pValue
}
```

Requires k >= 3 (need at least 1 df for residuals).

### Display

- **Analysis tab**: New "Egger's Test for Funnel Plot Asymmetry" card below the funnel plot:
  - Show intercept, SE, t-statistic, p-value
  - Interpretation text: "No evidence of funnel plot asymmetry" or "Evidence of funnel plot asymmetry (consider publication bias)"
  - Note: "Egger's test has low power with fewer than 10 studies"
- **Funnel plot**: Egger's regression line overlaid (dashed line from intercept through data)

## 3. SVG + PNG Export

### Implementation

Two buttons per chart card (forest plot and funnel plot):

**SVG export:**
1. Get `innerHTML` of the chart container (already valid SVG)
2. Wrap in XML declaration + xmlns attribute
3. Create `Blob` with MIME type `image/svg+xml`
4. Create temporary `<a>` element, set `href` to `URL.createObjectURL(blob)`
5. Trigger click, then `URL.revokeObjectURL()`

**PNG export:**
1. Serialize SVG to data URL via `XMLSerializer`
2. Create `Image`, set `src` to data URL
3. On `Image.onload`, draw to offscreen `<canvas>` at 2x resolution (retina)
4. Call `canvas.toBlob()` for PNG
5. Download via same Blob URL pattern, then revoke

### Filenames

- `rmst-forest-plot.svg` / `rmst-forest-plot.png`
- `rmst-funnel-plot.svg` / `rmst-funnel-plot.png`

### Display

- Export buttons added to card headers (alongside existing elements):
  - `[SVG]` `[PNG]` small secondary buttons
- Buttons only visible after analysis has been run (hidden when chart is empty)
